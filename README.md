# Azure MLOps Taxi Fare Regression

End-to-end MLOps project for predicting taxi fare using supervised regression.

## Project Objective

Build and deploy an end-to-end regression MLOps pipeline covering:

- Data ingestion
- Data validation
- Data cleaning
- Feature engineering
- Multiple regression models
- Hyperparameter tuning
- MLflow experiment tracking
- Automated testing
- Docker containerization
- Terraform infrastructure provisioning
- Azure Machine Learning
- Model registration
- Online model deployment
- REST API prediction
- CI/CD
- Monitoring and model drift
- Azure resource cleanup

## Technology Stack

- Python
- Pandas

- Scikit-learn
- XGBoost
- MLflow

- Azure Machine Learning
